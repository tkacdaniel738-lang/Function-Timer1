# Function-Timer

Навчальний проєкт з теми «Логування. Конфігурування логування. Тести».

## Що реалізовано

- `measure_time()` — запускає передану функцію, вимірює час її виконання та повертає пару `(результат, час)`.
- `timer_decorator()` — декоратор для вимірювання часу роботи функцій.
- Налаштування логування через стандартний модуль `logging`.
- Логування помилок із повторним викликом винятку.
- П'ять автоматичних тестів на базі `unittest`.

## Запуск

Потрібен Python 3.8 або новіший. Додаткові бібліотеки встановлювати не потрібно.

Запуск програми:

```bash
python main.py
```

Запуск тестів:

```bash
python -m unittest -v
```
